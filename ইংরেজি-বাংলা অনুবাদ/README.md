# ইংরেজি-বাংলা উইকিপিডিয়া অনুবাদ টুলকিট (English to Bengali Translation Toolkit)

ইংরেজি উইকিপিডিয়া নিবন্ধ, চলচ্চিত্র তালিকা, জীবনী, সারণি এবং উপাত্তসমূহকে প্রমিত বাংলা উইকিপিডিয়ার নীতিমালা মেনে বাংলায় অনুবাদ করার পূর্ণাঙ্গ কাঠামো।

---

## 📁 ফাইলের তালিকা ও কাঠামো

| ফাইল | বিবরণ |
|------|-------|
| `translate_page.py` | পূর্ণাঙ্গ পাতা অনুবাদক। নিবন্ধের ভূমিকা, অনুচ্ছেদ, সারণি, তথ্যসূত্র ও বিষয়শ্রেণী রূপান্তর করে। |
| `table_translator.py` | মিডিয়াউইকি সারণি (Wikitables) অনুবাদক। হেডার, সেল ও কলাম সমতা রক্ষা করে। |
| `links_dictionary.py` | ব্যক্তি, চলচ্চিত্র, সাহিত্য ও গুরুত্বপূর্ণ ইংরেজি নামের প্রমিত বাংলা অনুবাদ অভিধান। |
| `number_converter.py` | সংখ্যা, সাল, ক্রমবাচক সংখ্যা (1st, 2nd...) ও বড় অঙ্কের রূপান্তরক। |
| `cmudict.dict` | ইংরেজি নামের ধ্বনিতাত্ত্বিক প্রতিবর্ণীকরণের জন্য সিএমইউ উচ্চারণ অভিধান। |
| `clean_film_titles.json` | সংগৃহীত ও পরিশোধিত চলচ্চিত্র শিরোনাম ডাটাবেস। |
| `curated_all_654_films.json` | প্রমিত বাংলা উইকিলিংকসহ প্রস্তুতকৃত চলচ্চিত্র শিরোনামের পূর্ণাঙ্গ ম্যাপিং। |
| `notes_translations.json` | লাইভ অ্যাকশন ও অ্যানিমেশন সংক্রান্ত প্রায় ৪০০টি জটিল টীকার বাংলা অনুবাদ। |

---

## ⚙️ ব্যবহারের নিয়ম

### ১. পাইথন কোড থেকে
```python
from translate_page import translate_page, translate_text

# সম্পূর্ণ পাতা অনুবাদ:
translated_wikitext = translate_page("input.txt", "output.txt")

# অথবা টেক্সট স্ট্রিং অনুবাদ:
output_text = translate_text("== Early life ==\nJohn Doe was born in 1990...")
```

### ২. সারণি অনুবাদ:
```python
from table_translator import translate_wikitable

bn_table = translate_wikitable("""
{| class="wikitable"
! Title !! Director !! Year
|-
| [[The Godfather]] || Francis Ford Coppola || 1972
|}
""")
```

### ৩. কমান্ড লাইন থেকে
```bash
python translate_page.py input_article.txt output_article.txt
```

## 📋 অনুসৃত বাংলা উইকিপিডিয়া নীতিমালা
- **শতভাগ বাংলা সংখ্যা:** সমস্ত সাল, তারিখ, পৃষ্ঠা ও সংখ্যা `০-৯` হরফে রূপান্তর।
- **`{{Short description}}` বর্জন:** অপ্রয়োজনীয় রক্ষণাবেক্ষণ ট্যাগ অপসারণ।
- **উপভাষা টেমপ্লেট বর্জন:** `{{Use British English}}`, `{{Use dmy dates}}` ইত্যাদি সম্পূর্ণ অপসারিত।
- **এককের সুপারস্ক্রিপ্ট পরিহার:** `km²` এর বদলে সরাসরি `বর্গকিমি` ব্যবহার।
- **নুকতার প্রমিতকরণ:** বিশ্লিষ্ট নুক্তার বদলে প্রিকম্পোজড বর্ণ `য়`, `ড়`, `ঢ়` ব্যবহার।
- **সারণির সমতা ও খালি বাক্স রোধ:** খালি সেলে স্বয়ংক্রিয়ভাবে `&nbsp;` সংযোজন।
