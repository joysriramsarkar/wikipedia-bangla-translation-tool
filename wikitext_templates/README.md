# উইকিটেক্সট টেমপ্লেট (Wikitext Templates)

বাংলা উইকিপিডিয়ায় নিবন্ধ তৈরির জন্য প্রমিত উইকিটেক্সট টেমপ্লেট।

## তথ্যছক টেমপ্লেট

| ফাইল | বিবরণ | বাংলা টেমপ্লেট |
|------|-------|---------------|
| `infobox_settlement.wikitext` | বসতি/শহর/জেলা তথ্যছক | `{{তথ্যছক বসতি}}` |
| `infobox_person.wikitext` | ব্যক্তি তথ্যছক | `{{তথ্যছক ব্যক্তি}}` |
| `infobox_film.wikitext` | চলচ্চিত্র তথ্যছক | `{{তথ্যছক চলচ্চিত্র}}` |
| `infobox_country.wikitext` | দেশ তথ্যছক | `{{তথ্যছক দেশ}}` |

## সারণি টেমপ্লেট

| ফাইল | বিবরণ |
|------|-------|
| `film_list_table.wikitext` | চলচ্চিত্র তালিকার সারণি (৫ কলাম) |
| `admin_divisions_table.wikitext` | প্রশাসনিক বিভাগ সারণি |
| `leaders_list_table.wikitext` | রাষ্ট্রনেতা/প্রধানমন্ত্রী তালিকার সারণি |

## ব্যবহার নির্দেশিকা

### সারণির নিয়ম
- খালি ঘরে `&nbsp;` ব্যবহার করুন
- সারির বিভাজক `|-` সর্বদা পৃথক লাইনে রাখুন
- সমস্ত সংখ্যা বাংলা অঙ্কে (`০-৯`)
- বর্ণানুক্রম সর্বদা বাংলা (`অ-হ`)

### চলচ্চিত্র শিরোনাম উপস্থাপন
```wikitext
''[[বাংলা শিরোনাম]]'' (''মূল শিরোনাম'')
```

### তথ্যছক ব্যবহার
CX (ContentTranslation) থেকে অনুবাদ করা ইনফোবক্স স্বয়ংক্রিয়ভাবে রূপান্তরিত হয়
`cx_postprocess` পাইপলাইনের মাধ্যমে।
