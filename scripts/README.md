# স্ক্রিপ্ট (Scripts)

উইকিপিডিয়া অনুবাদ প্রকল্পের সহায়ক ইউটিলিটি স্ক্রিপ্টসমূহ।

## স্ক্রিপ্ট তালিকা

| স্ক্রিপ্ট | বিবরণ |
|-----------|-------|
| `fix_nukta.py` | বিশ্লিষ্ট নুক্তাযুক্ত বর্ণ (য+়, ড+়, ঢ+়) সংশোধন করে |
| `check_digits.py` | অনূদিত ফাইলে অবশিষ্ট ইংরেজি সংখ্যা পরীক্ষা করে |
| `sort_bengali.py` | উইকিটেক্সট সারণির সারি বাংলা বর্ণানুক্রমে (অ-হ) সাজায় |
| `verify_table.py` | সারণির কলাম সংখ্যার অসামঞ্জস্য ও সমস্যা পরীক্ষা করে |
| `stats.py` | সমস্ত অনূদিত ফাইলের পরিসংখ্যান প্রদর্শন করে |

## ব্যবহার উদাহরণ

```bash
# নুক্তা সংশোধন
python scripts/fix_nukta.py "জার্মান-বাংলা অনুবাদ/২০১০-এর দশকের জার্মান চলচ্চিত্রের তালিকা (বাংলা).txt"

# ইংরেজি সংখ্যা পরীক্ষা এবং স্বয়ংক্রিয় ঠিক করা
python scripts/check_digits.py "রুশ-বাংলা অনুবাদ/রাশিয়ার জেলা (বাংলা).txt" --fix

# বাংলা বর্ণানুক্রমে সাজানো
python scripts/sort_bengali.py "জাপানি-বাংলা অনুবাদ/জাপানিদের তালিকা (বাংলা).txt"

# সারণি যাচাই (৫ কলামের সারণি)
python scripts/verify_table.py "ইংরেজি-বাংলা অনুবাদ/আত্মজীবনীর তালিকা (বাংলা).txt" --expected-cols 5

# সকল ভাষার পরিসংখ্যান
python scripts/stats.py

# শুধু জাপানি অনুবাদের পরিসংখ্যান
python scripts/stats.py --lang japanese
```
