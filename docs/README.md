## পরিচিতি

এই টুলকিট বিভিন্ন ভাষার উইকিপিডিয়া নিবন্ধ, তথ্যছক, সারণি ও তালিকা
প্রমিত বাংলা উইকিপিডিয়ার নিয়ম অনুযায়ী অনুবাদ করার জন্য তৈরি।

**সমর্থিত ভাষা:**
- চীনা (Mandarin) → বাংলা
- জাপানি → বাংলা
- রুশ (Cyrillic) → বাংলা
- জার্মান → বাংলা
- ইংরেজি → বাংলা (CX পোস্ট-প্রসেসর)

## ভাষাভিত্তিক মডিউল

### ১. চীনা-বাংলা অনুবাদ (`চীনা-বাংলা অনুবাদ/`)

#### প্রধান মডিউল:
- **`transliteration.py`** — হানজি → বাংলা প্রতিবর্ণীকরণ ইঞ্জিন (pinyin ভিত্তিক)
- **`pinyin_table.py`** — পিনইন থেকে বাংলা ফোনেটিক ম্যাপিং সারণি
- **`links_dictionary.py`** — চীনা শহর, প্রদেশ, ব্যক্তিত্বের বাংলা লিংক অভিধান
- **`number_converter.py`** — চীনা/আরবি সংখ্যা → বাংলা অঙ্ক রূপান্তরক
- **`table_translator.py`** — প্রশাসনিক বিভাগ সারণি অনুবাদক
- **`translate_page.py`** — পূর্ণাঙ্গ পাতা অনুবাদ অর্কেস্ট্রেটর

#### ব্যবহার:
```python
import sys
sys.path.insert(0, 'চীনা-বাংলা অনুবাদ')
from transliteration import transliterate_hanzi_to_bengali

print(transliterate_hanzi_to_bengali("北京"))  # বেইজিং
print(transliterate_hanzi_to_bengali("上海"))  # শাংহাই
```

### ২. জাপানি-বাংলা অনুবাদ (`জাপানি-বাংলা অনুবাদ/`)

#### প্রধান মডিউল:
- **`japanese_transliteration.py`** — হেপবার্ন রোমাজি → বাংলা প্রতিবর্ণীকরণ ইঞ্জিন
- **`links_dictionary.py`** — সম্রাট, প্রধানমন্ত্রী, শহরের বাংলা লিংক অভিধান
- **`prime_minister_notes.py`** — প্রধানমন্ত্রীদের টীকা ও পাদটীকা পার্সার
- **`number_converter.py`** — জাপানি/আরবি সংখ্যা → বাংলা রূপান্তরক
- **`table_translator.py`** — সম্রাট/প্রধানমন্ত্রী তালিকা সারণি অনুবাদক
- **`translate_page.py`** — পূর্ণাঙ্গ পাতা অনুবাদ অর্কেস্ট্রেটর

#### নাম বিন্যাস নিয়ম:
জাপানি রাষ্ট্রপ্রধানদের ৩ স্তরে উপস্থাপন:
1. বাংলা নাম ও উইকিলিংক: `[[কিশিদা ফুমিও]]`
2. কাঞ্জি হরফ: `岸田 文雄`
3. IPA/রোমাজি ও জীবনকাল: `Kishida Fumio (জন্ম: ১৯৫৭)`

- **`links_dictionary.py`** — জার্মান ব্যক্তিত্ব ও স্থানের বাংলা অভিধান
- **`number_converter.py`** — জার্মান/আরবি সংখ্যা → বাংলা রূপান্তরক

#### বিশেষ নিয়ম (Z/Ts শব্দ):
শব্দের শুরুতে Z → স/সু (ৎ নয়):
- `Zimmermann` → `সিমারমান`
- `Zahlen` → `সালেন`

চলচ্চিত্র শিরোনাম উপস্থাপন:
```wikitext
''[[বাংলা শিরোনাম]]'' (''Das Original'')
```

## CX পোস্ট-প্রসেসর

ContentTranslation থেকে পাওয়া খসড়া উইকিটেক্সট স্বয়ংক্রিয়ভাবে পরিষ্কার করে।

### পাইপলাইন ক্রম (`cx_postprocess/pipeline.py`):
1. **`fix_templates`** — শিরোনাম/টেমপ্লেট নাম + templatestyles সাফাই
2. **`translate_infobox`** — প্যারাম/লেবেল + ভেতরে সংখ্যা
3. **`fix_tables`** — টেবিল গঠন; অ্যাট্রিবিউট সুরক্ষিত
4. **`fix_currency`** — মুদ্রা নাম — চিহ্ন রাখা হয়
5. **`fix_units_dates`** — billion/million, একক, মাস — শব্দ স্তর
6. **`to_bengali_digits_safe`** — শেষে সব দৃশ্যমান অঙ্ক → ০-৯

### API এন্ডপয়েন্ট:
| এন্ডপয়েন্ট | পদ্ধতি | বিবরণ |
|------------|--------|-------|
| `/dashboard` | GET | ওয়েব ড্যাশবোর্ড |
| `/health` | GET | সার্ভার স্বাস্থ্য পরীক্ষা |
| `/fix` | POST | উইকিটেক্সট পোস্ট-প্রসেস |
| `/validate` | POST | ১৩ নীতিমালার মধ্যে যাচাইযোগ্য ৯টির ফল |
| `/translate` | POST | মেশিন অনুবাদ + পোস্ট-প্রসেস |
| `/drafts` | GET/POST | খসড়া ট্র্যাকিং |
| `/preview` | POST | উইকিপিডিয়া API থেকে প্রাকদর্শন |
| `/translate_title` | GET | শিরোনাম অনুবাদ |

## বাংলা উইকিপিডিয়া নিয়ম

বিস্তারিত নিয়মের জন্য দেখুন: [`বাংলা_উইকিপিডিয়া_সম্পাদনা_নির্দেশিকা.md`](../বাংলা_উইকিপিডিয়া_সম্পাদনা_নির্দেশিকা.md)

**সারসংক্ষেপ:**
1. `{{Short description}}` পরিহার
2. সমস্ত সংখ্যা বাংলায় (`০-৯`)
3. বাংলা বর্ণানুক্রমিক তালিকা (`অ-হ`)
4. শব্দের শুরুতে 'ৎ' নিষিদ্ধ
5. `r.` → `শাসনকাল:`
6. সারণির কলাম সমতা (খালি ঘরে `&nbsp;`)
7. প্রি-কম্পোজড নুক্তা বর্ণ
8. একক: `বর্গকিমি` বা `কিমি<sup>২</sup>`

## উন্নয়ন গাইড

### নতুন ভাষা মডিউল যোগ করা

১. নতুন ফোল্ডার তৈরি করুন: `নতুনভাষা-বাংলা অনুবাদ/`
২. নিম্নলিখিত ফাইল তৈরি করুন:
   - `__init__.py`
   - `transliteration.py` — প্রতিবর্ণীকরণ ইঞ্জিন
   - `links_dictionary.py` — শব্দ/লিংক অভিধান
   - `number_converter.py` — সংখ্যা রূপান্তরক
   - `table_translator.py` — সারণি অনুবাদক
   - `translate_page.py` — পাতা অর্কেস্ট্রেটর
   - `README.md` — মডিউল ডকুমেন্টেশন
৩. `examples/demo.py`-এ ডেমো যোগ করুন
৪. `tests/`-এ টেস্ট যোগ করুন

### টেস্ট যোগ করা
```python
# tests/test_new_module.py
def test_transliteration():
    sys.path.insert(0, 'নতুনভাষা-বাংলা অনুবাদ')
    from transliteration import transliterate
    assert transliterate("Hello") == "হেলো"
```
