# চীনা-বাংলা অনুবাদ টুলকিট (Chinese to Bengali Translation Toolkit)

এই টুলকিটটি চীনা ভাষা ও উইকিপিডিয়ার বিভিন্ন তালিকা, নিবন্ধ ও সারণিসমূহকে বাংলা উইকিপিডিয়ার প্রমিত নিয়ম অনুযায়ী স্বয়ংক্রিয়ভাবে বাংলায় অনুবাদ করার জন্য প্রস্তুত করা হয়েছে।

---

## 📁 ফাইল ও মডিউল পরিচিতি

1. **`pinyin_table.py`**
   - বাংলা উইকিপিডিয়ার অফিসিয়াল নির্দেশনা (`উইকিপিডিয়া:বাংলা ভাষায় ম্যান্ডারিন চীনা শব্দের প্রতিবর্ণীকরণ`) অনুসারে ৪১৬টি ফিনিন সিলেবলের বাংলা রূপান্তর সারণি।
   - বিশেষ ভৌগোলিক নামের প্রমিত রূপান্তর সমন্বয়।

2. **`transliteration.py`**
   - `hanzi_to_bn(hanzi_str)`: যেকোনো চীনা হানজি টেক্সটকে প্রমিত বাংলায় প্রতিবর্ণীকরণ করে।
   - `pinyin_to_bn(pinyin_str)`: ফিনিন সিলেবলকে বাংলায় রূপান্তর করে।
   - `get_bengali_division_name(hz, en_link, type_str)`: প্রশাসনিক উপবিভাগের পূর্ণ বাংলা নাম প্রস্তুত করে (জেলা, কাউন্টি, শহর, ব্যানার, স্বায়ত্তশাসিত কাউন্টি ইত্যাদি)।
   - চীনের ৩৮টি সংখ্যালঘু জাতিগোষ্ঠীর বাংলা রূপান্তর মানচিত্র (`ETHNIC_MAP`)।

3. **`links_dictionary.py`**
   - উইকিপিডিয়ার প্রায় ৪০০টি চীনা প্রদেশ, প্রিফেকচার, শহর ও প্রশাসনিক বিভাগের প্রমিত বাংলা লিঙ্ক ও শিরোনাম অভিধান (`LINK_MAP`)।

4. **`number_converter.py`**
   - `to_bengali_digits(text)`: সব আরবি সংখ্যাকে (০–৯) বাংলায় রূপান্তর করে, কিন্তু উইকি টেবিলের এইচটিএমএল/সিএসএস অ্যাট্রিবিউট (`rowspan`, `colspan`, `font-size`, `width`, `#FFC0CB`, `display:none` ইত্যাদি) অক্ষুণ্ণ রাখে।
   - `translate_table_notes(text)`: সারণির সব ইংরেজি মন্তব্য ও জাতিগোষ্ঠীর নাম বাংলায় অনুবাদ করে।

5. **`table_translator.py`**
   - উইকিপিডিয়া টেবিল পার্সার ও অনুবাদক।
   - মূল উপবিভাগ সারণি, বিলুপ্ত কাউন্টি সারণি এবং নাম পরিবর্তন সারণি রূপান্তর করতে সক্ষম।

6. **`translate_page.py`**
   - পূর্ণাঙ্গ উইকিপিডিয়া পাতা অনুবাদের কমান্ড-লাইন ও পাইথন মডিউল।

7. **`pinyin_guide.wikitext`**
   - বাংলা উইকিপিডিয়ার মূল প্রতিবর্ণীকরণ নির্দেশিকা পাতার অফলাইন কপি।

## 🚀 ব্যবহারের নিয়ম

### ১. কমান্ড-লাইন থেকে সম্পূর্ণ পাতা অনুবাদ:
```bash
python translate_page.py "ইনপুট_ফাইল.txt" "আউটপুট_ফাইল.txt"
```

### ২. পাইথন স্ক্রিপ্ট থেকে ব্যবহার:
```python
from transliteration import hanzi_to_bn, get_bengali_division_name
from number_converter import to_bengali_digits
from translate_page import translate_wikipedia_page

# চীনা নাম বাংলায় রূপান্তর:
print(hanzi_to_bn("北京"))  # পেইচিং
print(get_bengali_division_name("瑶海区"))  # ইয়াওহাই জেলা

# সংখ্যা বাংলায় রূপান্তর:
print(to_bengali_digits("Area: 1,928.45 km², Pop: 629,535"))
# আউটপুট: Area: ১,৯২৮.৪৫ km², Pop: ৬২৯,৫৩৫

# পুরো ফাইল অনুবাদ:
translate_wikipedia_page("চীনের জেলা.txt", "চীনের জেলা (বাংলা).txt")
```
